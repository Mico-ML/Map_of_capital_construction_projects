# data/mock — демонстрационные данные (Приложение C ТЗ)

Все файлы каталога — **демо-данные** (`isMock: true`): они правдоподобны,
детерминированны (фиксированный seed — `MOCK_SEED` в `@oks/shared/config/mockGeneration`)
и явно помечаются бейджем «ДЕМО-ДАННЫЕ» в интерфейсе. Боевые источники
подключаются на этапах 2–4 дорожной карты (docs/ROADMAP.md, docs/INTEGRATIONS.md).

| Файл | Что заменяет | Боевой источник (этап 2+) |
|---|---|---|
| `population.csv` | Население МО (26 записей, «Росстат, оценка на 01.01.2025 (демо)») | Официальные выгрузки Росстата по МО / обезличенные данные операторов связи (адаптер `PopulationProvider`) |
| `media/` (SVG-кадры + `manifest.json`) | Кадры «До / В процессе / После» и снимки камер для 10 объектов | Генерируется `etl/tools/generate_mock_media.py`; реальные фото/рендеры — от заказчика, мозаики Sentinel-2/Landsat — `prepare_imagery_mosaic.py` (docs/IMAGERY.md) |
| `cameras` (в `media/manifest.json`) | «Живые» HLS-камеры подрядчиков | snapshot-заглушки с псевдо-«живым» таймстемпом; реальные HLS/RTSP — `CameraProvider=live` (docs/INTEGRATIONS.md) |
| `contracts` (генерируется сидом) | Закупки/контракты | ЕИС `zakupki.gov.ru` / `zakupki.tularegion.ru` по соглашению — **без скрапинга** (docs/INTEGRATION_EIS.md) |
| `appeals/satisfaction` (генерируется сидом) | Обращения граждан (ПОС, электронная приёмная) | Выгрузки ПОС «Госуслуги. Решаем вместе» (docs/INTEGRATION_POS.md) |

Замена источника не требует переделки UI: мок- и боевые реализации возвращают
структурно идентичные данные за общими интерфейсами-адаптерами (§10 ТЗ).
